## 台詞001：引かない — 名詞的な形と否定

### 本文

> తగ్గేదే లే

### 直訳

譲ることはない。

### 語彙説明

| 語句 | 意味 |
| --- | --- |
| తగ్గు | 減る・程度が下がる。ここでは譲ると読む |
| తగ్గేదే | 譲るという行為を取り上げて強調する部分 |
| లే | ない。口語の短い否定形として読む |

### 文法説明

| 部分 | 分解と働き |
| --- | --- |
| తగ్గు に基づく部分 | 減る・程度が下がるという動詞。ここでは態度を弱める、譲ると読む |
| -ే ＋ ది の部分 | 行為を名詞的に捉える分析。未来・習慣の連体形と名詞的な要素を区別する |
| 末尾の強調 -ఏ | その行為を強く否定する読みを支える。いつも「だけ」と訳す必要はない |
| లే | 存在否定の లేదు に対応する口語の短い形と読める |

程度を下げる行為を名詞のように取り上げ、それを「ない」と否定する形です。

### 補足

動詞の基本義は「減る・小さくなる」。ここでは相手に譲歩せず、「引かない」という態度を表します。

## 台詞002：パーティーはないのか — 否定疑問と呼びかけ

### 本文

> పార్టీ లేదా పుష్ప

### 直訳

パーティーは、ないか、プシュパ。

### 語彙説明

| 語句 | 意味 |
| --- | --- |
| పార్టీ | パーティー。英語からの借用語 |
| లేదా | ないか。この文では否定の問い |
| పుష్ప | プシュパ。呼びかける相手の名 |

### 文法説明

| 語・部分 | 働き |
| --- | --- |
| పార్టీ | 英語partyに対応する借用語。ここでは質問の対象 |
| లేదు ＋ 疑問の -ఆ | 存在否定を疑問にする分析。語末の母音が変わり、掲載文の లేదా になると読む |
| పుష్ప | 相手の名前。主語や所有者を示す格語尾ではなく、呼びかけと読む |

存在を否定する「ない」に疑問を加え、相手に答えを求める構造です。テルグ語の లేదా には選択の「または」という用法もありますが、ここでは前後に二つの選択肢が並ぶ構造ではなく、記事が説明する問いかけとして読みます。

### 補足

最後の人物名は、質問する相手への呼びかけです。パーティーが何を指すかは、この一文だけでは分かりません。

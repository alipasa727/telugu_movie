# Baahubali: The Beginning（2015）／バーフバリ 伝説誕生

『バーフバリ』前編の**テルグ語版**を題材に、掲載資料で確認できた短い台詞・歌詞を読む学習ノートです。タミル語版・ヒンディー語版の原文とは区別しています。確認日：2026年10月12日。

| 項目 | 内容 |
| --- | --- |
| 原題・表記 | బాహుబలి／Baahubali: The Beginning |
| 邦題 | バーフバリ 伝説誕生 |
| 公開年・監督 | 2015年／S. S. Rajamouli |
| 対象 | テルグ語音声の前編。後編の台詞・曲は含めない |
| 学習内容 | 所有形、強調、疑問、連体修飾、進行形、格、歌詞の省略 |
| 本編・字幕 | 今回は再生・照合していない。時刻と使用版は未確認 |

日本語訳はこのノートで作成した学習用訳です。原文の掲載確認、文法書の一般規則、本編の音声照合を分けて記録します。掲載サイトには誤記もあり得るため、短い引用をそのまま保存し、推測による修正や補作はしていません。

| [002：私と来るのは誰だ](dialogue/dialogue.md#dialogue-002) | 私と共に来るのは誰だ | 「私と」、連体形、疑問語、語の結合 |

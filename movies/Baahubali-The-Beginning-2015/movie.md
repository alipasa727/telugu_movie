# Baahubali: The Beginning（2015）／バーフバリ 伝説誕生

『バーフバリ』前編の**テルグ語版**を題材に、掲載資料で確認できた台詞・歌詞を意味のつながるまとまりで読む学習ノートです。タミル語版・ヒンディー語版の原文とは区別しています。初回確認日：2026年10月12日。まとまり単位の訳への改訂：2026年10月14日。

| 項目 | 内容 |
| --- | --- |
| 原題・表記 | బాహుబలి／Baahubali: The Beginning |
| 邦題 | バーフバリ 伝説誕生 |
| 公開年・監督 | 2015年／S. S. Rajamouli |
| 対象 | テルグ語音声の前編。後編の台詞・曲は含めない |
| 学習内容 | 所有形、強調、疑問、連体修飾、進行形、格、歌詞の省略 |
| 本編・字幕 | 今回は再生・照合していない。時刻と使用版は未確認 |

日本語訳はこのノートで作成した学習用訳です。台詞は一続きの発言、歌詞は意味がつながる箇所を一つのブロックに示し、まとまり全体の自然な訳・直訳の後に文法解説を置いています。原文の掲載確認、文法書の一般規則、本編の音声照合は分けて記録します。引用は採用資料に沿い、推測による修正や補作はしていません。

## 台詞

台詞は [1つのファイル](dialogue/dialogue.md) にまとめ、以下のリンクから各解説へ移動できます。

| ノート | 自然な訳・扱うまとまり | 学ぶこと |
| --- | --- | --- |
| [001：私の言葉こそが法](dialogue/dialogue.md#dialogue-001) | 自分の言葉が法であることを宣言する二文 | 所有形、強調の -ఏ、名詞の述語 |
| [002：私と共に生きるのは誰だ](dialogue/dialogue.md#dialogue-002) | 来る・死ぬ・死を越えて生きるという三つの問い | 「私と」、連体形、疑問語、反復 |
| [003：約束した人が死んでも、約束は残る](dialogue/dialogue.md#dialogue-003) | 人の死と約束の存続を対比する発言全体 | 連体修飾、可能性、逆接、後半の述語 |
| [004：あの男を焼くために薪を積む](dialogue/dialogue.md#dialogue-004) | 薪についての問い・現在の行為・その目的 | 疑問、進行形、一人称、目的を示す形 |

台詞集・記事に掲載された表現を使っています。Worthviewは003をカッタッパからAslam Jiへの発言、004をデーヴァセーナの発言として紹介しています。これは記事上の情報で、本編による確定とは分けています。002は映画記事が戦場で兵士を鼓舞する演説として紹介しています。

## 1. 原文

> తల్లే తన గురువు దైవం

## 2. 日本語訳

**自然な訳：** 母こそが、彼の師であり、神でもある。

**構造に沿った訳：** 母こそ、自分の師、神〔である〕。

「彼」は歌の対象であるバーフバリを受けた訳です。ただし、この一行に固有名はありません。「でもある」は並んだ二つの名詞を自然につなぐために補っています。

## 3. 語と文法

| 形 | 分解・働き |
| --- | --- |
| తల్లే | తల్లి（母）＋強調の -ఏ。母を際立たせる |
| తన | 自分自身に関わる所有を示す形。指す人物は文脈で判断する |
| గురువు | 師・先生。名詞の述語として読む |
| దైవం | 神・神聖な存在。同じく名詞の述語として読む |

動詞を明示せず、人が何者であるかを名詞で述べる行です。母への敬意を、教育する者と神聖な存在という二つの役割を重ねて表します。「母」と「神」が同じ辞書的意味なのではなく、この歌で同一の人物に重ねられています。

### 文法の根拠

参照：[Brown（1857、第2版）](https://www.scribd.com/document/318810861/A-Grammar-of-the-Telugu-Language-pdf)、冊子 p.168の連結動詞の省略、pp.172–175の強調。一般規則と原文を照合しました。再帰的な所有形の指示対象をバーフバリとすることは、歌の文脈に基づく分析です。

語義は共同編集辞書の Wiktionary の [母の項目](https://en.wiktionary.org/wiki/తల్లి)（Telugu → Noun）、[師の項目](https://en.wiktionary.org/wiki/గురువు)（Telugu → Etymology 1 → Noun）、[所有を表す項目](https://en.wiktionary.org/wiki/తన)（Telugu → Adjective）で確認しました。最後の項目は「自分の／彼の／彼女の」などを挙げています。指示対象をこの曲で誰とするかは、辞書の語義と別の解釈です。「神」の項目と、現代文法資料による照応範囲の確認は未完了です。

## 4. 会話との違い・未確認事項

強調と名詞述語は会話にも現れます。神にたとえる部分は賛歌の表現であり、日常の肩書の説明とは語調が異なります。

## 1. 原文

> బంగారు కలల్ని గుండెలోతు గాయాల్ని

## 2. 日本語訳

**自然な訳：** 金色に輝く夢を、心の奥深くの傷を。

**構造に沿った訳：** 金の夢〔複数〕を、心の深みの傷〔複数〕を。

この抜粋は二つの目的語で、文はまだ完結していません。後ろでは、それらを内に秘めながら流れ続ける命の川が描かれます。希望と痛みを同時に抱える存在として川を読むのは、歌全体の比喩に基づく解釈です。

## 3. 語と文法

| 形 | 分解・働き |
| --- | --- |
| బంగారు | 金・金色。後ろの「夢」を修飾する |
| కలల్ని | కల（夢）→複数形の語尾 -లు ＋対格 -ని。母音を落とした結合形として読む |
| గుండెలోతు | 心・胸の深みを表すまとまり。次の「傷」を修飾する |
| గాయాల్ని | 傷を表す語の複数形の語尾 -లు ＋対格 -ని。同じく母音を落とした結合形として読む |

複数の形の後に目的語の接辞が付き、短く結合した語尾が現れます。単に「夢は」「傷は」と主語に置き換えると、後続の動詞との関係を見失います。

### 文法の根拠と照合範囲

参照：[Brown（1857、第2版）](https://www.scribd.com/document/318810861/A-Grammar-of-the-Telugu-Language-pdf)、冊子 pp.200–201「Accusative」。対格で目的語を示す一般規則を参照します。掲載形の短縮された複数語尾を、現代口語の文法資料で項目別に再確認する作業は未完了です。古い文法書の活用表にこの短縮形がそのままあると主張していません。

語義のうち「夢」とその複数形は [Wiktionary の該当項目](https://en.wiktionary.org/wiki/కల)（Telugu → Noun）、「心臓・心」は [同辞書の該当項目](https://en.wiktionary.org/wiki/గుండె)（Telugu → Noun）で確認しました。共同編集辞書の確認であり、複数対格の短縮規則の文法書照合とは別です。「傷」と「金」の辞書項目の確認、および複合語全体の語義照合は未完了です。

## 4. 歌詞と会話・未確認事項

「金色」は希望や大切さを表す比喩として読めます。物としての金を表す意味と、ここでの感情的な働きを分けて捉えます。二つの目的語の間の「と」は自然な日本語のために補う場合がありますが、原文に独立した接続詞はありません。

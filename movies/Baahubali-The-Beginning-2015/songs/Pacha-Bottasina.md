## 1. 刺青の若者への呼びかけ

### 本文

> పచ్చ బొట్టేసిన పిల్లగాడా నీతో\
> పచ్చి ప్రాయాలనే పంచుకుంటానురా\
> జంట కట్టేసిన తుంటరోడ నీతో\
> కొంటె తంటాలనే తెచ్చుకుంటా దోర

### 直訳

緑の印を付けた若者よ、あなたと、まだ若い年月を〔私は〕分かち合う〔呼びかけ〕。対になったいたずら者よ、あなたと、いたずらな厄介事を〔私は〕自分に引き受ける、主よ。

### 語彙説明

- `పచ్చ బొట్టు`：緑の印、ここでは刺青として読む
- `పిల్లగాడా`：若者への呼びかけ
- `ప్రాయాలు`：若い年月
- `దోర`：主・殿に当たる呼びかけという解釈

### 文法説明

| 原文の形・要素 | 働きと訳へのつながり |
| --- | --- |
| `బొట్టేసిన పిల్లగాడా` | 印を付けたことを述べる過去の連体的な形が、呼びかけの名詞を修飾する。「印を付けた若者よ」 |
| `నీతో` | 二人称の形に -తో。「あなたと」。後ろの分かち合う述語までつなげる |
| `ప్రాయాలనే` | 若い年月に関わる複数の目的語と強調を含むものとして読む。主語ではない |
| `పంచుకుంటానురా` | 分ける動作に自分・相互の関与を示す結合があり、一人称の述語になる。末尾は親しい呼びかけとして読む |
| `జంట కట్టేసిన` | 対になる・結び付くことを後ろの人物に関係付ける。「結ばれた」の訳はここを受ける |
| `తెచ్చుకుంటా` | 持ってくる動作に自分への関与を示す結合があると読む。「厄介事も自分に引き受ける」という文脈上の訳 |

`-రా` は親しい呼びかけとして読めます。

### 補足

「緑の印」は刺青、「若い年月」は青春を表します。`దోర` は「主・殿」に当たる呼びかけですが、ここでは恋人へ向けています。

末尾に戻るサビは、`కొంటెయ్ తంటాలనే తెచుకుంటా దోర` と綴りが一部異なります。

## 2. 幾千の生と翼

### 本文

> వేయి జన్మల ఆరాటమై\
> వేచి ఉన్నానే ని ముందర\
> చేయి ని చేతిలో చేరగా\
> రెక్క విపిందే నా తొందర

### 直訳

千の生の切望となって、あなたの前で待っている。手があなたの手に合わさると、私のせっかちな思いは翼を広げた。

### 語彙説明

- `వేయి జన్మల`：千の生の
- `ఆరాటము`：切望として読む
- `చేయి`：手
- `రెక్క`：翼
- `తొందర`：急ぐ気持ち

### 文法説明

| 原文の形・要素 | 働きと訳へのつながり |
| --- | --- |
| `వేయి జన్మల ఆరాటమై` | 生の回数を表す名詞の関係と、「〜となって」に相当する結合を、待つ気持ちへつなぐ |
| `చేతిలో` | 場所を示す -లో。手の中という比喩の場所になる |
| `చేరగా` | 合わさる動作を、後続する出来事の時・条件として読む。-గా を単純に「だから」と固定しない |

### 補足

「千の生」は輪廻を思わせ、長く待ち望んだ恋を表します。はやる気持ちが翼を広げる、という比喩が続きます。`ని` は所有の `నీ`、`విపిందే` は「広げた」に当たる形と仮に読んでいます。

## 3. 美しさに引かれ、抱擁を求める

### 本文

> మాయగా నీ సోయగాలాలు వేసి\
> నన్నిలా లాగింది నువ్వే హలా\
> కబురులతో కాలాన్ని కరిగించే వ్రతమేళ\
> హత్తుకుపో నన్ను ఊపిరి ఆగేలా

### 直訳

魔法のように、あなたの美しさを〔働かせて〕、私をこのように引いたのは、まさにあなただ。おしゃべりで時間を溶かす誓いは、なぜ〔必要なのか〕。息が止まるように、私を抱き寄せて。

### 語彙説明

- `సోయగాలాలు`：美しさに関わる提示表記、語の切れ目は未確定
- `కబురులు`：おしゃべり
- `కాలం`：時間
- `ఊపిరి`：息
- `వ్రతమేళ`：「誓いがなぜ必要か」という問いと仮に読む

### 文法説明

| 原文の形・要素 | 働きと訳へのつながり |
| --- | --- |
| `నువ్వే` | 二人称の主格に強調。「ほかならぬあなたが／あなただ」 |
| `కబురులతో కాలాన్ని` | おしゃべりを手段、時間を対象として、溶かす動詞へ結び付ける |
| `నన్ను ఊపిరి ఆగేలా` | 抱擁の対象は「私を」。息が止まるような程度・結果を、動詞に添える |

### 補足

`సోయగాలాలు వేసి` と `హలా` は語の切れ目が不明瞭です。後続の「私を引いたのはあなただ」から、美しさに引き寄せられる流れと読めます。`వ్రతమేళ` は「誓いがなぜ必要か」という問いと仮に読み、話すより抱きしめてほしい、という願いへつなげています。

## 4. ジャスミンと抱擁

### 本文

> బహుబంధాల పొత్తిళ్ళలో విచుకున్నవే ఓహ్ మల్లికా\
> కోడే కౌగిలి పొత్తిళ్లలో కురి వీపింది నా కోరిక

### 直訳

腕の束縛という産着・懐の中で、あなたは開いた、ああ、ジャスミンよ。若々しい抱擁という懐の中で、私の願いは〔花開くように〕広がった。

### 語彙説明

- `మల్లికా`：ジャスミンへの呼びかけとして読む
- `కౌగిలి`：抱擁
- `పొత్తిళ్ళు`：産着・懐
- `కోరిక`：願い。`కురి వీపింది` の意味は未確定

### 文法説明

| 原文の形・要素 | 働きと訳へのつながり |
| --- | --- |
| `పొత్తిళ్ళలో` | 場所を示す -లో。懐の中という比喩の場所になる |
| `నా కోరిక` | 「私の願い」。前の不明瞭な動詞句を訳す際にも、この主語・中心名詞を残す |

### 補足

抱擁の中で花開くジャスミンに、恋の願いを重ねています。`బహుబంధాల`・`విచుకున్నవే`・`కురి వీపింది` は表記が不明瞭で、この部分の訳は仮のものです。

## 5. 一つの身体になり、すべてを委ねる

### 本文

> కానాలో నువ్వు నేను ఒక మెనూ కాగా\
> కొనాలో ప్రతి కొమ్మ మురిసెను గ\
> మరు క్షణమే ఎదురైనా\
> మరణం కూడా పరవసమే\
> సాంతం నే ని సొంతం ఆయైక

### 直訳

森の中であなたと私が一つの身体になると、谷・奥まった場所の枝の一つ一つが喜んだ。次の瞬間に向き合うことになっても、死さえも陶酔〔である〕。私がすっかりあなたのものになった後は。

### 語彙説明

- `కానాలో`／`కొనాలో`／`ఒక మెనూ`：森・奥まった場所・一つの身体と読む文脈上の推定
- `మరణం`：死
- `పరవసం`：陶酔として読む

### 文法説明

| 原文の形・要素 | 働きと訳へのつながり |
| --- | --- |
| `కాగా` | 一つの身体になる動作を、後続する出来事の時・条件として読む。第2節の -గా と同様、単純に「だから」と固定しない |
| `ఎదురైనా`・`కూడా` | 「出会うことになっても」と「〜さえも」を組み合わせ、死をも含む喜びの強調として読む |

### 補足

「死さえ至福」は、結ばれた喜びの強さを表す誇張です。`కానాలో`・`కొనాలో`・`ఒక మెనూ` は、森・奥まった場所・一つの身体と仮に読んでいます。

## 6. 月光と溶ける夜

### 本文

> చెమ్మ చేరేటి చెక్కిళ్ళలో\
> చిందులేసింది సిరి వెన్నెల\
> ప్రేమ ఊరెటి నీ కళ్ళలో\
> రేయ్ కరిగింధీ తేలి మంచులా

### 直訳

湿り気が届く頬の上で、豊かな月光が踊った。愛が湧き出るあなたの目の中で、夜が淡い霧のように溶けた。

### 語彙説明

- `చెమ్మ`：湿り気
- `చెక్కిళ్ళు`：頬
- `సిరి వెన్నెల`：豊かな月光
- `ప్రేమ`：愛
- `మంచు`：この提示形で霧・露・雪のどれかは未確定

### 文法説明

| 原文の形・要素 | 働きと訳へのつながり |
| --- | --- |
| `కళ్ళలో` | 場所を示す -లో。目の中という比喩の場所になる |
| `ప్రేమ ఊరెటి నీ కళ్ళలో` | 愛が湧き出るという説明が、「あなたの目」を修飾する読み |
| `మంచులా` | 名詞に「〜のように」を添える比喩の形と読む。名詞の具体的な意味はこの節の補足のとおり未確定 |

### 補足

`చెమ్మ` は湿り気。頬の潤い、豊かな月光、愛の湧き出る瞳を重ねた情景です。末尾の `తేలి మంచులా` は「淡い霧のように」と仮訳しています。

## 台詞 001：私の言葉こそが法 — 宣言をひとまとまりで読む

**自然な訳：** これが私の言葉だ。その言葉こそが、法なのだ。

### 原文の出典

| 項目 | 内容 |
| --- | --- |
| 作品・言語 | Baahubali: The Beginning（2015）／テルグ語 |
| 掲載資料 | [Telugu Bucket：Prabhas Baahubali 1 Telugu Movie Dialogues](https://telugubucket.com/prabhas-baahubali-1-telugu-movie-dialogues/) |
| 参照箇所 | 台詞第10項の宣言全体 |
| 確認状況 | この会話でウェブ本文の作品名と表記を確認。後半だけを抜き出していたノートを、前後の二文を含む一つの発言に更新 |
| 本編照合 | 未実施。正確な話者・相手・時刻・使用版は未確認 |

### 1. 原文のまとまり

> ఇది నా మాట. నా మాటే శాసనం.

前半で自分の言葉であることを示し、後半でその言葉の効力を宣言する、一続きの発言です。

### 2. 構造に沿った直訳と補足

**構造に沿った訳：** これ〔は〕私の言葉〔である〕。私の言葉こそ、法〔である〕。

日本語でも二文にしていますが、訳の対象はこの発言全体です。後半の「その」は、繰り返される「私の言葉」を自然につなぐための訳です。原文では同じ名詞句を繰り返し、言葉と権威を強く結び付けています。

### 3. 全体訳を支える語と文法

| 形・要素 | 分解・文中の働き |
| --- | --- |
| ఇది | 近くのものを指す「これ」。ここでは発言・宣言を受けると読む |
| నా | 一人称単数の所有形。「私の」。後ろの名詞を修飾する |
| మాటే | మాట（言葉・発言）＋強調の -ఏ。後半では同じ言葉を強調して述べる |
| శాసనం | 命令・法令に当たる名詞。ここでは「法」と訳す |

前半も後半も、名詞を述語として読む形です。「だ」に当たる動詞は原文に明示されていません。強調を「私の言葉だけが唯一の法律」と厳密な排他に固定せず、この宣言が拘束力を持つことを強く主張する働きとして読んでいます。

#### 根拠と確認範囲

[Brown（1857、第2版）](https://www.scribd.com/document/318810861/A-Grammar-of-the-Telugu-Language-pdf)、冊子 pp.68–70「Pronouns」、p.168の連結動詞の省略、pp.172–175「Emphatic affixes」。同書の一般規則を本文で確認し、今回の名詞句と宣言へ適用しています。指示語がこの発言を受けるという説明は、前後関係に基づく分析です。

語義は [Wiktionary「మాట」](https://en.wiktionary.org/wiki/మాట) の発言・言葉の項目を参照。「法令」に当たる名詞の辞書項目の確認は未完了です。

## 台詞 002：私と共に生きるのは誰だ — 三つの問いをひとまとまりで読む

**自然な訳：** 私と共に来るのは誰だ。私と共に死ぬのは誰だ。死を乗り越え、私と共に生きるのは誰だ。

| 掲載資料 | [Filmibeat：Dev Katta's inspirational dialogue in Baahubali](https://telugu.filmibeat.com/news/dev-katta-s-inspirational-dialogue-baahubali-046825.html)／2015年7月16日 |
| 参照箇所 | 記事中で一続きに引用された、兵士に呼びかける三つの問い全体 |
| 比較資料 | [Worthviewの台詞集](https://movie-dialogues.worthview.com/baahubali-the-beginning-movie-dialogues-with-images-prabhas-rana-anushka/) の戦場の演説。主にローマ字表記で掲載 |
| 確認状況 | 作品への帰属、掲載原文、戦場の演説という記事の説明を本文で確認 |
| 本編照合 | 未実施。使用版・正確な時刻・音声の語境界は未確認 |

### 1. 原文のまとまり

> నాతో వచ్చేదెవరు...నాతో చచ్చేదెవరు...చావుని దాటుకుని నాతో బ్రతికేదెవరు !

最初の問いだけで区切らず、「来る」「死ぬ」「死を乗り越えて生きる」という順に重なる呼びかけを、一つのまとまりとして扱います。句読点・綴りは採用資料の掲載形です。

### 2. 構造に沿った直訳と補足

**構造に沿った訳：** 私と、来る〔者／のは〕誰か。私と、死ぬ〔者／のは〕誰か。死を越えて、私と、生きる〔者／のは〕誰か。

三つの疑問を重ね、兵士に参加と覚悟を問いかける演説です。最後まで読むことで、死の覚悟を問うだけで終わらず、死を越えて共に生きることへ向かう流れが分かります。この説明は掲載された問いの順序と記事の場面説明に基づきます。

### 3. 全体訳を支える語と文法

| 形・要素 | 分解・文中の働き |
| --- | --- |
| నాతో | నా ＋ -తో。「私と」。三つの問いで反復され、共同行動の相手を示す |
| 各問いの末尾 | 動詞の連体的・名詞的なまとまりと、疑問語 ఎవరు（誰）を結び付ける |
| 死を示す目的語 | 末尾の -ని を対格として読む。「死を」の対象が、続く越える動作につながる |
| 「越えて」の部分 | 一つの動作を後続の「生きる」に結び付ける。細かい複合動詞の分解は追加照合事項 |

一つずつの問いを独立した教材にせず、反復される「私と」と「誰」の間で動作が変わっていく構造を読みます。疑問の形を、日本語訳だけを根拠に命令形と説明することはしません。

#### 根拠と確認範囲

[Brown（1857、第2版）](https://www.scribd.com/document/318810861/A-Grammar-of-the-Telugu-Language-pdf)、冊子 pp.68–70の代名詞、pp.200–203の格、pp.253–254「Relative Aorist Participle」を参照。代名詞の格、対格、連体的な動詞の形を名詞や「誰」に結び付ける一般規則を本文で確認しています。

今回の縮約形の語境界や、死を越える複合動詞の細かな形成を同書で直接確認したわけではありません。一般規則、原文への当てはめ、未確認の分析を分けています。

## 台詞 003：約束した人が死んでも、約束は残る — 発言全体を読む

**自然な訳：** 約束した人は死ぬことがあっても、その約束は残る。

### 原文の出典

| 項目 | 内容 |
| --- | --- |
| 作品・言語 | Baahubali: The Beginning（2015）／テルグ語 |
| 掲載資料 | [Filmibeat：Baahubali Dialogues](https://telugu.filmibeat.com/movies/baahubali/dialogues.html) |
| 参照箇所 | 2015年のテルグ語作品の台詞欄、第2項の全文 |
| 比較資料 | [Worthviewの台詞集](https://movie-dialogues.worthview.com/baahubali-the-beginning-movie-dialogues-with-images-prabhas-rana-anushka/) の約束に関する段落 |
| 確認状況 | 掲載本文で作品表示と原文を確認。WorthviewはカッタッパがAslam Jiに向ける言葉として紹介している |
| 本編照合 | 未実施。話者・相手は比較記事上の情報で、音声で確定したものではない |

### 1. 原文のまとまり

> మాట ఇచ్చిన వాళ్ళు చనిపోవచ్చు కానీ...మాట నిలిచిపోతుంది

「約束した人たち」という名詞句だけで切らず、人の死と約束の存続を対比する発言の全体を扱います。

### 2. 構造に沿った直訳と補足

**構造に沿った訳：** 言葉を与えた人たちは、死ぬかもしれない。しかし、言葉は残り続ける。

「言葉を与える」は、この文脈では「約束する」と訳します。「その」は、前半の言葉を受けていることを日本語で示す補足です。自然な訳では複数の人を、日本語の一般的な「約束した人」としています。原文の複数を単数の活用だと説明するものではありません。

### 3. 全体訳を支える語と文法

| 文中の要素 | 分解・働き |
| --- | --- |
| 約束した人たち | 「与えた」に当たる過去の連体形が、後ろの人を指す複数代名詞を修飾する |
| 過去の連体形 | ఇచ్చి ＋ -న と見る形。「与える」の基本形と区別する |
| 死ぬかもしれない | 可能性を示す述語として読む。人がすでに死んだという過去の断定ではない |
| しかし | 前半と後半を逆接でつなぐ |
| 約束が残る | 同じ「言葉」が再び現れ、人の寿命とは別に存続するものとして述べられる |

修飾する節を読んだ後、述語、逆接、後半の述語までつなげます。「約束した人たち」だけを名詞句として訳して終えると、この発言の中心である対比が失われます。

#### 根拠と確認範囲

[Brown（1857、第2版）](https://www.scribd.com/document/318810861/A-Grammar-of-the-Telugu-Language-pdf)、冊子 p.86の分詞形成、p.252「Past Relative Participle」。過去の分詞を連体形にして後ろの名詞・人を修飾する規則を本文で確認しています。

語義は [Wiktionary「మాట」](https://en.wiktionary.org/wiki/మాట) の Telugu → Noun 第3義「約束」と、言葉を与える約束の用例で確認。可能性や存続を表す複合動詞の細かな語幹・接辞は、今回の文脈に基づく読みとして記録し、辞書・現代文法資料の項目別確認は未完了です。

### 4. 資料の違いと追加確認事項

Worthviewのローマ字掲載文には、死んでいる可能性を述べる形や相手への呼びかけがあり、Filmibeatの文と完全に同じではありません。話者を調べる比較資料として使い、二つの資料の文を継ぎ合わせて原文を作ってはいません。本編での実際の発話形・話者・相手を追加確認する必要があります。

## 台詞 004：あの男を焼くために薪を積む — 問いと決意をひとまとまりで読む

| 確認状況 | 掲載原文を本文で確認。Worthviewはデーヴァセーナの言葉として掲載 |

### 1. 原文のまとまり

> పుల్లలు ఏరుకోవడానికి నేను పిచ్చి దాన్ననుకున్నావా కట్టప్పా.. చితి పేరుస్తున్నాను..ఆ భల్లాల దేవుణ్ని కాల్చడానికి

問い、現在の行為、その目的までを一つの発言として読みます。掲載資料の句読点と分かち書きを維持しています。

### 2. 構造に沿った直訳と補足

**構造に沿った訳：** 薪を拾うために、私を愚かな女だと思ったのか、カッタッパ。〔私は〕火葬の薪の山を積んでいる。あのバラーラデーヴァを焼くために。

自然な訳の「ただ〜だけ」は、薪を拾うように見える行動と、その本当の目的との対比を伝える補足です。日本語の冒頭は掲載文の語順をそのまま移すと不自然なので、問いの意味が通るように組み直しています。最後の目的を含めることで、薪を積む行為が復讐の準備だと分かります。

### 3. 全体訳を支える語と文法

| 文中の要素 | 分解・働き |
| --- | --- |
| 拾うために／焼くために | いずれも動作の目的を示す形。末尾の -డానికి を含む。前半と最後で、同じ目的の形が対比される |
| 思ったのか | 相手の判断を問い返す形。末尾の長い -ఆ を疑問として読む |
| カッタッパへの呼びかけ | 相手を指す呼格。語尾だけで親しさや敬意を確定しない |
| 薪を積んでいる | 進行形に一人称単数の情報がある。独立した「私」がない箇所でも、訳では主語を補う |
| 焼く対象 | 人名に目的語を示す接辞が付き、焼く動作の対象になる |

原文の最後は目的を示す句ですが、発言の前半の行為を受けて意味が完結します。文末の目的句を独立した短い教材に切り分けず、問いと決意の流れで訳しています。

#### 根拠と確認範囲

[Brown（1857、第2版）](https://www.scribd.com/document/318810861/A-Grammar-of-the-Telugu-Language-pdf)、冊子 pp.91–95の現在形、p.168の主語などの省略、pp.172–173の疑問、pp.200–203の格・呼格を参照。一般規則の本文確認と、今回の語尾への適用を区別しています。

目的を表す現代形の詳しい形成、思う動詞の縮約、薪を積む動詞の基本形と語幹交替は追加確認事項です。進行形の一般規則だけを根拠に、すべての口語形まで照合済みとは扱いません。

> పరమేశ్వరా, నేను చేసిన పాపాలకు ప్రాయశ్చిత్తంగా నా ప్రాణాలు తీసుకో. కానీ ఈ బిడ్డ బతకాలి. వీడి కోసం ఎదురు చూస్తున్న కన్నతల్లి కోసం బతకాలి. మాహిష్మతి సింహాసనం కోసం బతకాలి. మహేంద్ర బాహుబలి బతకాలి!

句読点と文の区切りは読みやすく補いました。画像で2行になっている王座と目的の句は、一つの文としてつなげています。ローマ字からは長母音・子音の種類・重子音がすべて明確になるわけではないため、`e` を `ఈ`、`thisko` を `తీసుకో`、`prayashchithamga` を `ప్రాయశ్చిత్తంగా`、`Maahismathi` を `మాహిష్మతి` とする部分などに、一般的な語形からの推定が含まれます。これはテルグ文字で掲載された原文の転載ではありません。

### 2. 構造に沿った直訳と補足

**構造に沿った訳：** パラメーシュヴァラよ、私がした罪に対する償いとして、私の命を取れ。しかし、この子は生きる必要がある。この子のために待っている生みの母のために、生きる必要がある。マヒシュマティの王座のために、生きる必要がある。マヘンドラ・バーフバリは、生きる必要がある。

命を差し出す申し出と、「しかし」以後の子の生存を願う言葉を、一続きの祈りとして訳しています。`తీసుకో` は相手への命令・求めとして読みますが、日本語の自然な訳では神への祈りに合わせて「お取りください」としました。原文に日本語と同じ敬語の形が明示されているという意味ではありません。

`బతకాలి` の繰り返しは、各文で理由や名指す相手が変わります。母、王座、マヘンドラの名へと願いを重ねる流れを伝えるため、この発言では省略していません。最後の「のです」は、日本語で断固とした願いを伝える補足です。

### 3. 全体訳を支える語と文法

| 形・まとまり | 働きと訳へのつながり |
| --- | --- |
| `నేను చేసిన పాపాలకు` | 「私がした」という過去の連体的な節が「罪」にかかる。末尾の -కు を含め、後続の償いとの関係として読む |
| `ప్రాయశ్చిత్తంగా` | 償い・贖罪を表す名詞に -గా が付き、命を取ることを「償いとして」と位置付ける |
| `నా ప్రాణాలు తీసుకో` | 「私の命を取ってくれ」という求め。命を表す語は複数形だが、日本語では一人の「命」と訳す |
| `కానీ ఈ బిడ్డ బతకాలి` | 逆接の「しかし」で、自分の命と子の命を対比する。-ాలి の形を必要・強い願いとして読み、祈りの文脈では子の生存への切実さを表す |
| `వీడి కోసం ఎదురు చూస్తున్న కన్నతల్లి కోసం` | 内側の「この子のために待っている」が母を修飾し、外側の「母のために」が生きる理由になる。二つの `కోసం` をそれぞれの関係へ結び付ける |
| `మాహిష్మతి సింహాసనం కోసం` | 王座を、生きることのもう一つの目的・理由として示す。原文にない将来の出来事や王位継承の詳細は補わない |
| `మహేంద్ర బాహుబలి బతకాలి` | 最後に子の名前を明示し、それまでの生存への願いを一人の人物へ集める |

`బతకాలి` は「生きる」に必要・当為・願いを表す形が続くものとして読んでいます。ここを一般的な規則の命令とだけ説明せず、神へ訴える祈りの中で「この子だけは生きてほしい」と強く願う働きとして解釈しました。

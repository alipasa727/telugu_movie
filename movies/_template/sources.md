# ［映画タイトル］の資料と確認記録

台詞ノートとは別に、採用原文・語義・文法の根拠と照合状況を記録します。資料の一般規則と、映画の表現への当てはめを区別してください。

## 台詞ごとの資料記録

### 台詞001：［短い見出し］

| 項目 | 記録する内容 |
| --- | --- |
| 原文の出典 | ［資料名・URL・種類・著者等。提供画像の場合は識別できる特徴］ |
| 掲載範囲 | ［見出し・項目・行・ページなど。原文の採用範囲と省略］ |
| 確認日・方法 | ［年月日。本文確認・画像の読取りなど］ |
| 語義・文法 | ［辞書の見出し、文法資料の節・ページ、確認した規則］ |
| 本編との照合 | ［版・言語・字幕・時刻。未照合ならその旨］ |
| 未確認・不一致 | ［表記差や追加照合が必要な分析］ |

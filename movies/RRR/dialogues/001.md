## 1. テルグ語の原文

> పులిని పట్టుకోవాలంటే వేటగాడు కావాలి.

[OkTeluguの記事](https://oktelugu.com/news/rrr-movie-dialogues-in-telugu-202085.html) の同じ一文とも一致する。後続の「その仕事ができるのは一人だけ」は [002](002.md) で扱う。

## 2. 日本語訳

**自然な訳：** 虎を捕まえるには、狩人が必要だ。

**直訳：** 虎を捕まえようというなら、狩人が要る。

「捕まえることが目標なら、それに適した人が必要だ」という条件と必要の組み合わせ。「虎」を誰かの比喩と読むことはできるが、掲載文だけでは指す人物を確定できない。「あなたが」「我々が」は原文にないので訳に加えていない。

## 3. 語と文法

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| పులిని | పులి（虎）＋ -ని（対格） | 捕まえる対象。「虎を」 |
| పట్టుకోవాలంటే | పట్టుకో-（捕まえる）に必要・意向を含む形と అంటే が続くまとまり | 「捕まえようというなら／捕まえるには」。補助解説は必要・意向を含む部分と条件の అంటే を分けて分析している |
| వేటగాడు | 狩人 | 必要とされる人 |
| కావాలి | 要る・必要だ・欲しい | 後半の述語。ここでは「狩人が必要だ」 |

**文の組み立て：** 前半は「虎を捕まえること」を条件として置き、後半は必要な人を示す。కావాలి を常に「欲しい」と訳すと、ここでは必要条件という関係が見えにくくなる。

### 根拠と照合範囲

| 確認した事項 | 参照箇所・今回の照合 |
| --- | --- |
| 語義 | [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)：పులి p.778の第2見出し「虎」、పట్టు p.702の動詞項目「つかむ」、వేట p.1226内のవేటకాడు「狩人」を本文で確認。辞書のవేటకాడుと掲載文のవేటగాడుは表記が異なるため、引用は掲載文を保つ |
| 対格 -ని | [Mahesh](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=15)、スライド15「Declensions」の目的語を表す ni/nu を పులిని に当てはめた |
| 必要を表す構文 | [Arden](https://archive.org/details/aprogressivegra00ardegoog)、§437 p.176：与格と「要る／欲しい」に相当する述語の構文。古い形の説明であり、現代形కావాలిの音形そのものをこの節で確認したとはしない |
| -వాలంటే と కావాలి の現代形 | [Mirchi Bajji](https://note.com/telugu/n/n6e1df8df5af2)「03 PULINI PATTUKOVALANTE」の形の分解と訳を確認。個人の補助資料として参照 |

**文法の確認状況：** 対格は文法資料で照合済み。条件を含む現代形の細かな分解は補助資料による。-వాలంటే 全体を単なる条件語尾として覚えるより、行為の目標と条件をまとめる表現として読む。

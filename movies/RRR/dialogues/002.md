## 1. テルグ語の原文

> ఆ పని చేయగలిగేది ఒక్కడే సార్

Filmibeatの掲載部分をそのまま抜粋した。原文末尾には句点がない。[OkTeluguの記事](https://oktelugu.com/news/rrr-movie-dialogues-in-telugu-202085.html) では末尾の呼びかけを సర్ と表記する。この差を黙って統一しない。

## 2. 日本語訳

**自然な訳：** その仕事ができるのは、たった一人です。

**直訳：** その仕事をすることができるのは、一人だけです、サー。

自然な訳では末尾の呼びかけを独立して訳さず、「です」に相手への敬意を込めた。前の文との関係では「その仕事」は虎を捕まえることを受ける。「一人」の名前はこの抜粋にはないため、訳に補っていない。

## 3. 語と文法

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| ఆ | その・あの | పని を限定する指示語 |
| పని | 仕事・用事 | చేయ- の対象。ここでは対格の語尾が付いていない |
| చేయగలిగేది | చేయ-（する）＋ గలిగే-（できる、の連体形）＋ -ది（名詞として受ける部分） | 「することができるのは」に相当するまとまり |
| ఒక్కడే | ఒక్కడు（一人の男性）に強調の -ఏ が付いた形 | 「たった一人／一人だけ」 |
| సార్ | 英語の sir に由来する呼びかけ | 相手を敬って呼ぶ。主語・目的語ではない |

**文の組み立て：** 「その仕事をできること／できるのは」を先に示し、答えとして「一人だけ」を置く。日本語の「〜できるのは、〜だ」に近い。గలిగేది を過去の「できた」としない。ここで重要なのは連体形の -ఏ と、それを名詞として受ける -ది である。

-ది はこの構文を名詞としてまとめる働きがある。「女性だから -ది」と解釈せず、文全体の構造を見る。男性を指す形は後半の ఒక్కడే に現れている。

### 根拠と照合範囲

| 確認した事項 | 参照箇所・今回の照合 |
| --- | --- |
| 語義 | [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)：పని p.712、చేయు p.435、కలుగు p.259の動詞項目（能力を表す用例を含む）、ఒకడు p.206を確認。ఒక్కడుそのものの見出し検索は結果なし。語中の子音重複を辞書が解説したとはしない |
| 動詞＋能力の補助動詞 | [Arden](https://archive.org/details/aprogressivegra00ardegoog)、§460 p.185の不定形＋能力の補助動詞；[Mahesh](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=32)、スライド32「Other tenses/voices」の cēya＋galugu を原文に当てはめた |
| 連体形と名詞化 | Arden §263 p.97の不定・一般の連体形、§540–544 pp.217–220の連体形＋代名詞的接辞と事柄を表す名詞化を確認。今回の「〜できるのは」という構造に適用 |
| 名詞述語の「〜だ」 | Arden §383 p.151の、現在の連結動詞を明示しない構文を参照。日本語訳の「です」はここで補った |
| 強調の -ఏ | Arden §183 p.72の強調接辞の説明を確認。ただし、この接辞一般の強調と、今回の「一人だけ」という限定の読みを区別する。後者はこの台詞への当てはめ |

**文法の確認状況：** 能力と名詞化の一般規則は文法書・概説で照合済み。現代形 గలిగే- の詳細な活用、ఒక్కడు と -ఏ の接合、限定の意味範囲は追加照合が必要。歴史的な文法書のすべての形を現代会話へ一般化していない。

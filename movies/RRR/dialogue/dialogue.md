## 台詞001：虎を捕まえるには — 条件と必要

### 場面と出典

| 項目 | 内容 |
| --- | --- |
| 掲載資料 | [Filmibeat：RRR Dialogues](https://telugu.filmibeat.com/movies/rrr-roudram-ranam-rudhiram/dialogues.html)／台詞集 |
| 掲載箇所 | 「డైలాగ్」内の虎・狩人に関する項目の最初の一文 |
| 話者・相手・場面 | 掲載資料では特定されていない。以下のニュアンスは文の意味に基づく解釈 |
| 確認日・方法 | 2026年10月11日。ページ本文でRRRへの帰属とテルグ文字の表記を確認 |
| 本編の音声・字幕、時刻 | 未照合・未確認 |

### 1. テルグ語の原文

> పులిని పట్టుకోవాలంటే వేటగాడు కావాలి.

[OkTeluguの記事](https://oktelugu.com/news/rrr-movie-dialogues-in-telugu-202085.html) の同じ一文とも一致する。後続の「その仕事ができるのは一人だけ」は [002](#dialogue-002) で扱う。

### 2. 日本語訳

**自然な訳：** 虎を捕まえるには、狩人が必要だ。

**直訳：** 虎を捕まえようというなら、狩人が要る。

「捕まえることが目標なら、それに適した人が必要だ」という条件と必要の組み合わせ。「虎」を誰かの比喩と読むことはできるが、掲載文だけでは指す人物を確定できない。「あなたが」「我々が」は原文にないので訳に加えていない。

### 3. 語と文法

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| పులిని | పులి（虎）＋ -ని（対格） | 捕まえる対象。「虎を」 |
| పట్టుకోవాలంటే | పట్టుకో-（捕まえる）に必要・意向を含む形と అంటే が続くまとまり | 「捕まえようというなら／捕まえるには」。補助解説は必要・意向を含む部分と条件の అంటే を分けて分析している |
| వేటగాడు | 狩人 | 必要とされる人 |
| కావాలి | 要る・必要だ・欲しい | 後半の述語。ここでは「狩人が必要だ」 |

**文の組み立て：** 前半は「虎を捕まえること」を条件として置き、後半は必要な人を示す。కావాలి を常に「欲しい」と訳すと、ここでは必要条件という関係が見えにくくなる。

#### 根拠と照合範囲

| 確認した事項 | 参照箇所・今回の照合 |
| --- | --- |
| 語義 | [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)：పులి p.778の第2見出し「虎」、పట్టు p.702の動詞項目「つかむ」、వేట p.1226内のవేటకాడు「狩人」を本文で確認。辞書のవేటకాడుと掲載文のవేటగాడుは表記が異なるため、引用は掲載文を保つ |
| 対格 -ని | [Mahesh](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=15)、スライド15「Declensions」の目的語を表す ni/nu を పులిని に当てはめた |
| 必要を表す構文 | [Arden](https://archive.org/details/aprogressivegra00ardegoog)、§437 p.176：与格と「要る／欲しい」に相当する述語の構文。古い形の説明であり、現代形కావాలిの音形そのものをこの節で確認したとはしない |
| -వాలంటే と కావాలి の現代形 | [Mirchi Bajji](https://note.com/telugu/n/n6e1df8df5af2)「03 PULINI PATTUKOVALANTE」の形の分解と訳を確認。個人の補助資料として参照 |

**文法の確認状況：** 対格は文法資料で照合済み。条件を含む現代形の細かな分解は補助資料による。-వాలంటే 全体を単なる条件語尾として覚えるより、行為の目標と条件をまとめる表現として読む。

### 4. 表記の違いと追加照合

Mirchi Bajjiの掲載文では狩人の語を分かち書きし、後続文もFilmibeatと異なる。異なる文をつなぎ合わせず、ここではFilmibeatの一文を採用した。

現代口語文法で -వాలంటే の構成と కావాలి の用法をさらに照合する。本編の話者・相手・比喩の指示対象・発音・時刻は未確認。

## 台詞002：できるのは一人だけ — 能力と強調

### 場面と出典

| 項目 | 内容 |
| --- | --- |
| 掲載資料 | [Filmibeat：RRR Dialogues](https://telugu.filmibeat.com/movies/rrr-roudram-ranam-rudhiram/dialogues.html)／台詞集 |
| 掲載箇所 | 「డైలాగ్」内、虎を捕まえるには狩人が必要だ、という文に続く部分 |
| 話者・相手・時刻 | 掲載資料では特定されていない。末尾の呼びかけは相手への敬意を示す |
| 確認日・方法 | 2026年10月11日。掲載本文の表記とRRRへの帰属を確認 |
| 本編の音声・字幕 | 未照合 |

### 1. テルグ語の原文

> ఆ పని చేయగలిగేది ఒక్కడే సార్

Filmibeatの掲載部分をそのまま抜粋した。原文末尾には句点がない。[OkTeluguの記事](https://oktelugu.com/news/rrr-movie-dialogues-in-telugu-202085.html) では末尾の呼びかけを సర్ と表記する。この差を黙って統一しない。

### 2. 日本語訳

**自然な訳：** その仕事ができるのは、たった一人です。

**直訳：** その仕事をすることができるのは、一人だけです、サー。

自然な訳では末尾の呼びかけを独立して訳さず、「です」に相手への敬意を込めた。前の文との関係では「その仕事」は虎を捕まえることを受ける。「一人」の名前はこの抜粋にはないため、訳に補っていない。

### 3. 語と文法

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| ఆ | その・あの | పని を限定する指示語 |
| పని | 仕事・用事 | చేయ- の対象。ここでは対格の語尾が付いていない |
| చేయగలిగేది | చేయ-（する）＋ గలిగే-（できる、の連体形）＋ -ది（名詞として受ける部分） | 「することができるのは」に相当するまとまり |
| ఒక్కడే | ఒక్కడు（一人の男性）に強調の -ఏ が付いた形 | 「たった一人／一人だけ」 |
| సార్ | 英語の sir に由来する呼びかけ | 相手を敬って呼ぶ。主語・目的語ではない |

**文の組み立て：** 「その仕事をできること／できるのは」を先に示し、答えとして「一人だけ」を置く。日本語の「〜できるのは、〜だ」に近い。గలిగేది を過去の「できた」としない。ここで重要なのは連体形の -ఏ と、それを名詞として受ける -ది である。

-ది はこの構文を名詞としてまとめる働きがある。「女性だから -ది」と解釈せず、文全体の構造を見る。男性を指す形は後半の ఒక్కడే に現れている。

#### 根拠と照合範囲

| 確認した事項 | 参照箇所・今回の照合 |
| --- | --- |
| 語義 | [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)：పని p.712、చేయు p.435、కలుగు p.259の動詞項目（能力を表す用例を含む）、ఒకడు p.206を確認。ఒక్కడుそのものの見出し検索は結果なし。語中の子音重複を辞書が解説したとはしない |
| 動詞＋能力の補助動詞 | [Arden](https://archive.org/details/aprogressivegra00ardegoog)、§460 p.185の不定形＋能力の補助動詞；[Mahesh](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=32)、スライド32「Other tenses/voices」の cēya＋galugu を原文に当てはめた |
| 連体形と名詞化 | Arden §263 p.97の不定・一般の連体形、§540–544 pp.217–220の連体形＋代名詞的接辞と事柄を表す名詞化を確認。今回の「〜できるのは」という構造に適用 |
| 名詞述語の「〜だ」 | Arden §383 p.151の、現在の連結動詞を明示しない構文を参照。日本語訳の「です」はここで補った |
| 強調の -ఏ | Arden §183 p.72の強調接辞の説明を確認。ただし、この接辞一般の強調と、今回の「一人だけ」という限定の読みを区別する。後者はこの台詞への当てはめ |

**文法の確認状況：** 能力と名詞化の一般規則は文法書・概説で照合済み。現代形 గలిగే- の詳細な活用、ఒక్కడు と -ఏ の接合、限定の意味範囲は追加照合が必要。歴史的な文法書のすべての形を現代会話へ一般化していない。

## 台詞003：お前を逮捕する — 目的語と進行形

### 場面と出典

| 項目 | 内容 |
| --- | --- |
| 掲載資料 | [OkTelugu：RRR Movie Dialogues in Telugu](https://oktelugu.com/news/rrr-movie-dialogues-in-telugu-202085.html)／Shiva、2022年4月12日／映画記事 |
| 掲載箇所 | 「RRR Movie Dialogues in Telugu」内、「చరణ్:」で始まる逮捕の項目の末尾 |
| 話者 | 記事は俳優名「చరణ్」（チャラン）で台詞を帰属させている |
| 相手・場面 | 逮捕を告げる発言。相手の名前と具体的な場面は当該掲載項目では示されていない |
| 確認日・方法 | 2026年10月11日。掲載本文で原文・作品・俳優への帰属を確認 |
| 本編の音声・字幕、時刻 | 未照合・未確認 |

### 1. テルグ語の原文

> నిన్ను అరెస్ట్ చేస్తున్నాను.

長い掲載文の末尾からの短い抜粋。前半は、英国政府に逆らった罪を理由として述べる部分である。前半を省いたことにより、ここでは逮捕の理由を文法解説の対象にしていない。

### 2. 日本語訳

**自然な訳：** お前を逮捕する。

**直訳：** （私は）お前を逮捕している。

「私は」は原文に独立した代名詞としては現れないが、動詞の一人称単数の形を日本語で見えるように補った。自然な訳は、逮捕をその場で告げる発言として読む。日本語の「逮捕している最中だ」に限られるわけではない。

నిన్ను は二人称単数の目的語形。「あなたを」とも訳せるが、この告知では「お前を」とした。この代名詞だけから、侮辱・怒りなどの感情を断定しない。

### 3. 語と文法

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| నిన్ను | 二人称単数の対格・目的語形 | 逮捕される対象。「お前を」。主語形に単純に -ను を足すだけの形とは説明しない |
| అరెస్ట్ | 英語 arrest をテルグ文字で表記した借用語 | 後ろの「する」と組み合わさって逮捕という行為を表す |
| చేస్తున్నాను | చేయు（する）に基づく చేస్తున్న- ＋一人称単数を示す語尾 | 「私はしている」。進行形の補助動詞 ఉండు に基づく構成 |

**文の組み立て：** 目的語の「お前を」→借用語＋動詞の「逮捕している」の順。主語の代名詞は省かれているが、動詞の形が話し手一人を示す。英語の語を使っていても、動詞の時制・人称はテルグ語で作られている。

#### 根拠と照合範囲

| 確認した事項 | 参照箇所・今回の照合 |
| --- | --- |
| 目的語形と人称 | [Arden](https://archive.org/details/aprogressivegra00ardegoog)、§171 p.69（二人称代名詞の格変化）、§249 pp.92–93（ఉండుに基づく現在形と人称）。公開OCRの英語説明を参照し、崩れたテルグ文字を引用原文には使っていない |
| 語義と「名詞＋する」 | [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)、చేయు p.435の「する・行う」と、投獄などの名詞と組み合わさる用例を確認。映画の英語借用語自体が辞書に載っていたとはしない |
| 進行形の構成 | [Mahesh](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=32)、スライド32：చేయుに基づく動詞部分＋ఉండుの現在形という構成を確認。[Arden](https://archive.org/details/aprogressivegra00ardegoog) §264 p.97の進行形の縮約と、§249の人称の説明を合わせて చేస్తున్నాను に適用 |

**文法の確認状況：** 目的語・進行形・人称の一般規則を資料で照合した。「逮捕する」という自然な訳は発言の内容からの解釈であり、文法資料が映画のこの場面を説明しているわけではない。

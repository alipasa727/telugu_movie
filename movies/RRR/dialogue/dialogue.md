## 虎を捕まえるには狩人が必要だ

### 本文

> పులిని పట్టుకోవాలంటే వేటగాడు కావాలి. ఆ పని చేయగలిగేది ఒక్కడే సార్

**日本語訳：** 虎を捕まえるには、狩人が必要だ。その仕事ができるのは、たった一人です。

### 直訳

虎を捕まえようというなら、狩人が要る。その仕事をすることができるのは、一人だけです、サー。

### 語彙説明

| 語句 | 意味 |
| --- | --- |
| పులిని | 虎を |
| పట్టుకోవాలంటే | 捕まえようというなら・捕まえるには |
| వేటగాడు | 狩人 |
| కావాలి | 要る・必要だ・欲しい |
| ఆ పని | その仕事 |
| చేయగలిగేది | することができるのは |
| ఒక్కడే | たった一人 |
| సార్ | サー。敬意を込めた呼びかけ |

### 文法説明

#### 前半：条件と必要

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| పులిని | పులి（虎）＋ -ని（対格） | 捕まえる対象。「虎を」 |
| పట్టుకోవాలంటే | పట్టుకో-（捕まえる）に必要・意向を含む形と అంటే が続くまとまり | 「捕まえようというなら／捕まえるには」。補助解説は必要・意向を含む部分と条件の అంటే を分けて分析している |
| వేటగాడు | 狩人 | 必要とされる人 |
| కావాలి | 要る・必要だ・欲しい | 後半の述語。ここでは「狩人が必要だ」 |

**文の組み立て：** 前半は「虎を捕まえること」を条件として置き、後半は必要な人を示す。కావాలి を常に「欲しい」と訳すと、ここでは必要条件という関係が見えにくくなる。

<a id="dialogue-002"></a>

#### 後半：能力と強調

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| ఆ | その・あの | పని を限定する指示語 |
| పని | 仕事・用事 | చేయ- の対象。ここでは対格の語尾が付いていない |
| చేయగలిగేది | చేయ-（する）＋ గలిగే-（できる、の連体形）＋ -ది（名詞として受ける部分） | 「することができるのは」に相当するまとまり |
| ఒక్కడే | ఒక్కడు（一人の男性）に強調の -ఏ が付いた形 | 「たった一人／一人だけ」 |
| సార్ | 英語の sir に由来する呼びかけ | 相手を敬って呼ぶ。主語・目的語ではない |

**文の組み立て：** 「その仕事をできること／できるのは」を先に示し、答えとして「一人だけ」を置く。日本語の「〜できるのは、〜だ」に近い。గలిగేది を過去の「できた」としない。ここで重要なのは連体形の -ఏ と、それを名詞として受ける -ది である。

-ది はこの構文を名詞としてまとめる働きがある。「女性だから -ది」と解釈せず、文全体の構造を見る。男性を指す形は後半の ఒక్కడే に現れている。

### 補足

**流れ：** 「何を達成したいか」→「どんな人が必要か」→「それをできる人は一人だけ」という説明。同じ掲載項目の2文を続けて訳した。掲載資料は各文の話者を明示していないため、同じ人物が続けて発話したことまでは確定しない。

自然な訳では末尾の呼びかけを「です」に込めています。「その仕事」は前半の虎を捕まえることを受けます。「一人」の名前は原文にないため加えていません。

Mirchi Bajjiの掲載文では狩人の語を分かち書きし、後続文もFilmibeatと異なる。異なる文をつなぎ合わせず、ここではFilmibeatの一文を採用した。

現代口語文法で -వాలంటే の構成と కావాలి の用法をさらに照合する。本編の話者・相手・比喩の指示対象・発音・時刻は未確認。

前半の補助資料Mirchi Bajjiでは後続文の語がFilmibeat・OkTeluguと異なるため、後半の原文としては採用しなかった。本編の音声で呼びかけや終わり方を確認する必要がある。

## 英国政府に逆らった罪で逮捕する

### 本文

> బ్రిటీష్ ప్రభుత్వానికి ఎదురు తిరిగిన నేరానికి, నిన్ను అరెస్ట్ చేస్తున్నాను.

**日本語訳：** 英国政府に反抗した罪で、お前を逮捕する。

### 直訳

英国政府に逆らった罪のために、（私は）お前を逮捕している。

### 語彙説明

| 語句 | 意味 |
| --- | --- |
| బ్రిటీష్ ప్రభుత్వం | 英国政府 |
| ఎదురు తిరిగిన | 逆らった |
| నేరానికి | 罪のために・罪で |
| నిన్ను | お前を・あなたを |
| అరెస్ట్ | 逮捕。英語からの借用語 |
| చేస్తున్నాను | 〔私は〕している |

### 文法説明

| 原文の形 | 分解・意味 | 文中の働き |
| --- | --- | --- |
| నిన్ను | 二人称単数の対格・目的語形 | 逮捕される対象。「お前を」。主語形に単純に -ను を足すだけの形とは説明しない |
| అరెస్ట్ | 英語 arrest をテルグ文字で表記した借用語 | 後ろの「する」と組み合わさって逮捕という行為を表す |
| చేస్తున్నాను | చేయు（する）に基づく చేస్తున్న- ＋一人称単数を示す語尾 | 「私はしている」。進行形の補助動詞 ఉండు に基づく構成 |

**文の組み立て：** 目的語の「お前を」→借用語＋動詞の「逮捕している」の順。主語の代名詞は省かれているが、動詞の形が話し手一人を示す。英語の語を使っていても、動詞の時制・人称はテルグ語で作られている。

#### 前半の理由を読む

政府に「向き合って、逆らった」という部分が「罪」を修飾し、その罪を理由として告知へ続く。[Arden](https://archive.org/details/aprogressivegra00ardegoog)§262 p.97（過去の連体形）・§513 pp.206–207（名詞への修飾）と、[Mahesh](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=15)スライド15の格の一般規則を参照。今回の「罪で」はこの文への当てはめである。

### 補足

**流れ：** 先に逮捕の理由を述べ、最後に相手への告知を置く。「逮捕する」だけを抜き出すと失われていた理由を、同じ掲載文の前半と一緒に訳した。

「私は」は動詞の一人称単数から補っています。「お前」は二人称単数の訳で、この形だけから怒りや侮辱を断定しません。

本編の相手・場面・発音・字幕表記・時刻。借用語の綴りは掲載資料の అరెస్ట్ を保ち、別の綴りへ書き換えていない。

## 小物より大物を — 狩りの比喩と誘い

### 本文

> భీం, ఈ నక్కల వేట ఎంతసేపు..! కుంభస్థలాన్ని బద్దలు కొడదాం పదా.

**日本語訳：** ビーム、いつまで小物を相手にしている？ 大物の急所を砕きに行こう。

### 直訳

ビーム、このジャッカル狩りはいつまでだ？ 象の額のふくらみを打ち砕こう、さあ行こう。

### 語彙説明

| 語句 | 意味 |
| --- | --- |
| భీం | ビーム。呼びかける相手の名 |
| నక్కల వేట | ジャッカル狩り |
| ఎంతసేపు | どれほどの時間・いつまで |
| కుంభస్థలాన్ని | 象の額のふくらみを。複合語の語義は構成語からの読み |
| బద్దలు కొడదాం | 打ち砕こう |
| పదా | さあ行こうという促しとして読む |

### 文法説明

- 前半は呼びかけに続く時間の質問。「狩り」をいつまで続けるのかと問う。後半は一人称複数の誘いを「〜しよう」と訳し、末尾の促しを「さあ行こう」とした。
- 狩りの対象は複数で、属格の形が後ろの名詞を修飾する。後半の対象には対格の語尾があり、打ち砕く対象を示す。
- [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)の本文で、నక్క p.628（ジャッカル）、వేట p.1226（狩り）、సేపు p.1360（時間）、కుంభము p.290（象の額のふくらみ）、బద్ద p.871（破片）、కొట్టు pp.316–317（打つ）を確認。額の複合語全体の完全一致検索は結果がなく、構成語と文脈から読んだことを区別する。
- [Maheshの文法概説](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=15)スライド15：属格の複数語尾・対格の一般規則。[Arden文法書](https://archive.org/details/aprogressivegra00ardegoog)§269 pp.97–98：一人称複数の命令・勧誘に相当する一般規則。現代形の個々の音変化をそのまま紙面で確認したとはしない。

### 補足

「ジャッカル」と「象の額」を対比する比喩として読み、自然な訳では「小物」「大物の急所」とした。「大物」「急所」はこの対比を伝えるための解釈で、原文に独立した同義の語があるわけではない。「相手にしている」「砕きに行こう」も日本語の流れに合わせた補い。敵の具体的な人物名・組織名は訳に加えていない。

額の複合語の現代辞書での見出し、促しの末尾の現代口語形、比喩の具体的な指示対象、本編の話者・場面・時刻。掲載サイト間の違いを音声で確認する。

## ゴンドの猛虎、コムラム・ビーム

### 本文

> వాడు కనపడితే సముద్రాలూ తడపడతాయ్.\
> నిలపడితే సామ్రాజ్యాలు సాకిలపడతాయ్.\
> వాడి పొగరు ఎగిరే జెండా.\
> వాడి ధైర్యం చీకట్లను చీల్చే మండుటెండ.\
> వాడు భూతల్లి చనుపాలు తాగిన ముద్దు బిడ్డ.\
> నా తమ్ముడు గోండు బెబ్బులి కొమురం భీం.

**日本語訳：** あいつが姿を現せば、海さえおののく。立ちはだかれば、帝国がひれ伏す。あいつの誇りは、はためく旗。勇気は、闇を切り裂く灼熱の陽光だ。母なる大地の乳を飲んで育った、愛しい子。俺の弟、ゴンドの猛虎、コムラム・ビームだ。

### 直訳

あの男が見えれば、海も動揺する。立てば、帝国が身を伏せる。あの男の傲慢さは飛ぶ旗で、勇気は闇を裂く焼けつく日差し。あの男は大地の母の乳を飲んだ愛しい子で、私の弟、ゴンドの虎、コムラム・ビームだ。

### 語彙説明

| 語句 | 意味 |
| --- | --- |
| వాడు | あの男・あいつ |
| సముద్రాలూ | 海も |
| సామ్రాజ్యాలు | 帝国 |
| పొగరు | 誇り・傲慢さ |
| జెండా | 旗 |
| ధైర్యం | 勇気 |
| మండుటెండ | 焼けつく日差し。構成語からの読み |
| భూతల్లి | 母なる大地 |
| ముద్దు బిడ్డ | 愛しい子 |
| నా తమ్ముడు | 私の弟 |
| గోండు బెబ్బులి | ゴンドの虎 |

### 文法説明

#### 旗の比喩

- 所有を示す「あの男の」＋「誇り」が前半。「飛ぶ／はためく」という連体修飾が「旗」にかかり、その名詞句が述語になる。
- [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)：పొగరు p.808（誇り・傲慢さ）、ఎగురు p.183の動詞項目（飛ぶ）、జెండా p.468（旗）の本文を確認。
- [Arden文法書](https://archive.org/details/aprogressivegra00ardegoog)：§173–174 pp.69–70（三人称の代名詞と格）、§263 p.97（一般の連体形）、§513 pp.206–207（名詞を修飾する形）、§383 p.151（肯定の名詞述語で「〜である」を明示しない構文）を参照。日本語の「だ」はこの名詞述語の関係を表す。

<a id="dialogue-006"></a>

#### 日差しの比喩

- 「あの男の勇気」が主題。「闇を裂く」というまとまりが、後ろの「焼けつく日差し」を修飾し、その名詞句全体が述語になる。
- 闇の語は複数に対格の語尾が付いた形。日本語の「闇」は数を明示しなくても自然なので、「複数の闇」とは訳していない。
- [Brown辞書](https://dsal.uchicago.edu/dictionaries/brown/)：ధైర్యము p.625（勇気）、చీకటి p.422（闇）、చీలు p.424内の他動詞の異形（裂く）、మండు p.941（燃える）、ఎండ p.179（熱・日差し・輝き）を確認。掲載文の勇気の語は辞書の見出しと語末が異なる。複合語全体の語義を直接引けたとはせず、構成語からの読みとして記録する。
- [Mahesh](https://cse.iitk.ac.in/users/maheshak/pdf/telugu_by_mahesh.pdf#page=15)スライド15の複数対格と、[Arden](https://archive.org/details/aprogressivegra00ardegoog)§263 p.97・§513 pp.206–207の連体修飾、§383 p.151の名詞述語の一般規則を原文に当てはめた。

### 補足

**流れ：** まず海や帝国さえ動揺する人物として描き、誇りを旗、勇気を日差しにたとえ、母なる大地とのつながりを示す。最後に、その人物がビームだと名乗り上げる。以前の旗・日差しの2文だけでは分からなかった「誰を紹介する言葉か」を、この6行で読めるようにした。

「誇り」には傲慢さの語義もありますが、人物をたたえる流れに合わせて訳しています。「立ちはだかる」「育った」は補足です。「弟」は親しい紹介として保ち、この発言だけで血縁関係と断定しません。

最初の2行には、標準的な辞書の形と異なる掲載形がある。動揺する動詞の見出し తడబడు p.503などを手がかりに暫定的に読んだが、引用は訂正せず掲載文を保った。立つ動詞・身を伏せる動詞の活用と、口語・誤記のどちらかは音声または現代辞書で追加確認する。

所有を示す代名詞の現代形と、飛ぶ動詞の現代連体形の活用は追加照合する。紹介文からの肯定的な読みと、辞書の語義を分けて記録した。人物の感情・声の調子・本編の時刻は未確認。

「焼けつく日差し」の複合語の現代辞書での見出し、名詞の複数形の音変化、本編の話者・時刻・比喩の指示対象。紹介文の6行は同じ掲載欄に連続する本文であり、別の掲載文を合成していない。

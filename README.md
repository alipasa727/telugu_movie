# 映画の台詞と歌詞で学ぶテルグ語

映画の台詞と歌詞を題材に、テルグ語の表現がどのように意味を作るかを学ぶためのノートです。テルグ文字が読めることを前提に、**原文・日本語訳・文法解説**を結び付け、別の場面でも使える理解を積み重ねます。

## 学習の方針

原文を読み、語幹と接辞の働きを追い、訳の根拠を自分で説明できることを目指します。場面や人物関係も合わせて読むことで、辞書の訳語だけでは分からない語調や使い方を理解します。

映画の会話では口語の短縮や省略を、歌詞では比喩・反復・詩的な語順を学びます。それぞれの表現が日常会話でどう使えるかも考え、作品中の言い方と一般的な用法を区別します。

テルグ文字を本文の中心に置きます。ローマ字やカタカナは必要な場合の補助とし、発音は音声で確かめます。

## 教材の選び方

テルグ語の台詞・歌詞から、学習したい表現や文法に合う箇所を選びます。テルグ語原語版と吹替版を区別し、使用する音声・字幕・掲載原文の言語を確認します。一つのノートでは、意味と構造を説明できる一続きの発言・会話、歌詞の節・段落を扱います。

- 日常でも使える呼びかけ、質問、返答、依頼、否定などを取り上げる。
- 格、人称、時制、動詞の活用、連体修飾など、学ぶポイントが明確な箇所を選ぶ。
- 有名な決め台詞だけに偏らず、会話のやり取りや人物関係が分かる表現も増やす。
- 歌詞は比喩や省略を説明できる箇所を選び、理解に必要な前後関係を日本語で補う。

台詞は意味がつながる発言・やり取りを単位にし、次の5項目をこの順で置きます。

1. **本文**：確認した原文だけを掲載。
2. **直訳**：主語・目的語・修飾関係を追える訳。
3. **語彙説明**：本文の形・辞書形・品詞・意味と、活用や語尾の働き。
4. **文法説明**：文の骨格から、格・活用・語順が意味を作る仕組みを説明。
5. **補足**：背景、比喩、補った語句の根拠、表記差や未確認事項。

台詞ごとの「場面と出典」欄や、辞書・文法資料の参照記録は設けません。

歌詞も台詞と同じ構成にそろえ、節やサビなど小節のまとまりごとに、次の5項目をこの順で置きます。

1. **本文**：原文だけを、行の区切りを保って掲載。
2. **直訳**：まとまり全体の意味と構造を追う訳。
3. **語彙説明**：本文の形・辞書形・品詞・意味と、活用や語尾の働き。
4. **文法説明**：文の骨格から、修飾・語尾・行をまたぐつながりを説明。
5. **補足**：文化的な背景、比喩、訳で補った内容、表記の差や未確認事項。

台詞・歌詞とも、日本語の訳は「直訳」にまとめます。「本文」には原文だけを置き、直訳の前に別の日本語訳を重ねません。

文法の都合で短い一文だけに切り分けず、指示語が受ける内容や比喩の流れが分かる範囲を選びます。別資料の文や離れた場面は合成しません。同じ歌詞の繰り返しは省略し、新しく現れる内容と表記差を残します。

## 原文の扱い

台詞・歌詞ノートには、原文の提供元・出典・底本・取得日・照合状況を表示しません。「原文情報」欄や確認表も付けません。テルグ語の本文と、訳の理解に必要な背景・語義の不明点を掲載します。

資料で確認できた表記と推測を混同しません。意味に関わる表記差や不明な語は補足で説明し、読めない部分を作って埋めません。

**台詞・歌詞は自作せず、必ず調べて出典を確認します。** 記憶やAIの生成文だけを根拠に、作品中の原文として掲載しません。原文が見つからない場合は作って補わず、掲載を見送るか未確認事項として残します。

日本語訳と文法解説は、確認した原文に基づいて作成します。原文にない内容を訳で補う場合は、その旨を明記します。

## 調査に使う資料

台詞・歌詞は、ユーザーが提示した本文・画像や、本編・公式字幕・公式歌詞など、実際に採用する原文を基にします。提供本文と本編の音声・字幕との照合状況は区別し、原文を自作したり、未確認の表記を推測で埋めたりしません。

語義や文法の確認には辞書・文法書・教育資料を使います。共通の一覧は [辞書・文法資料](SOURCES.md) にまとめています。作品別・台詞別・曲別の参照記録や照合表、調査履歴は管理しません。使わなくなった映画サイトの候補一覧も残しません。

## 日本語訳の方針

**直訳**では、主語・目的語・修飾関係や接辞の働きが追えるように、まとまり全体を訳します。場面や語調に関わる解釈は補足で説明します。

省略された主語や目的語を補った場合は、補った内容と根拠を説明します。人称の訳し分け、丁寧さ、感情、比喩など、解釈が入る部分も原文の意味と分けて示します。複数の読み方がある場合は、無理に一つに決めず、文脈に合う解釈と残る疑問を記録します。

日本語訳は学習用に作成し、公式字幕と混同しません。

## 文法解説の方針

初心者が、本文のどの語がどう変化し、何を表しているかを追える解説にします。語彙は「本文の形／辞書形／品詞／意味／活用・語尾の働き」の表にそろえます。名詞なら単数・複数や「〜を・〜に」の形、動詞なら誰の動作か、時制、否定、命令や条件などを示します。

品詞欄の略語と語の分解の表記は、[文法説明の凡例](GRAMMAR.md)にまとめています。語の分解と語尾の説明は語彙説明に置き、文法説明では文全体の構造とつながりを説明します。

文法は「誰が・何をするか」という骨格から始め、どの語がどの名詞を説明するか、どの語尾が前後をつなぐかを順に読みます。用語だけで済ませず、その働きを日本語で添えます。

| 用語 | このノートでの意味 |
| --- | --- |
| 辞書形・語幹 | 辞書で引く基本の形と、語尾が付く土台。語尾が付くと土台の音も変わることがある |
| 名詞・代名詞 | 人や物事の名を表す語と、「私・これ」など、その代わりに使う語 |
| 動詞・形容詞・副詞 | 動作や状態を述べる語、名詞の性質を説明する語、動作や程度などを説明する語 |
| 後置詞 | 名詞などの後ろに置き、場所・方向・比喩などの関係を示す語 |
| 活用・屈折 | 時制・人称・数・格などに応じて、語の形が変わること |
| 格・所有形 | 「〜を・〜に・〜の」など、名詞や代名詞とほかの語との関係。対格は「〜を」、与格は「〜に」、所有形・属格は「〜の」 |
| 人称・数 | 一人称は話し手、二人称は相手、三人称はそれ以外。単数は一人・一つ、複数は二つ以上 |
| 非過去 | 過去以外の動作を表す形。文脈に応じて習慣・一般的な事実・これからの動作などを表す |
| 連体形・名詞化 | 動詞を使って後ろの名詞を説明する形と、動作を「〜すること・もの」としてまとめること |
| 命令・条件・譲歩 | 「〜しろ」という促し、「〜なら」というつながり、「〜しても」というつながり |

**文法事項も、文法書・大学や教育機関の教材で調べて根拠を確認します。** 語義は辞書、格・活用・構文は文法資料で確認し、口語と書き言葉を区別します。調べた節・ページや語句ごとの確認履歴を蓄積せず、説明に必要な不確実さだけを補足に示します。

共通の参照先は [テルグ語の辞書・文法資料](SOURCES.md#テルグ語の辞書文法資料) にまとめています。根拠を確認できない分析は未確認と明記し、AIの説明だけで確認済みにはしません。

- 格を表す接辞と、動詞の時制・人称・数などを示す形を区別する。
- 単語の分解だけで終わらず、文全体の構造と日本語訳へのつながりを示す。
- 口語形と書き言葉の形は、対応が確認できた場合に併記する。
- 歌詞の比喩や反復は、文字どおりの意味と表現上の効果を分けて説明する。

一つの語尾を常に同じ日本語に置き換えるのではなく、その形の働きと文脈の両方から読むことを重視します。

解説は、語句の意味・文のつながり・比喩を短く自然な日本語で伝えます。確認作業や編集手順の断り書きを各節に繰り返さず、意味に関わる不明点だけを、その箇所の補足に短く示します。補足がなければ空欄にします。

## 内容の更新

新しい資料で誤りや別の解釈が分かった場合は、原文・訳・解説を見直し、未確認だった点を更新します。

## 言語版と資料の区別

このノート集ではテルグ語版を扱います。原文・訳・文法・出典はテルグ語の資料で調べ、タミル語など別言語の資料の確認結果を転用しません。

| 項目 | 確認する内容 |
| --- | --- |
| 原語・文字・作品情報 | テルグ語の原題・公開年・曲名を確認し、タミル語の原作とテルグ語吹替版を区別する |
| 台詞・歌詞の原文 | 提供本文・画像や採用資料の言語と作品を確認する。別言語版の原文や検証結果を転用しない |
| 辞書・文法資料 | テルグ語の資料で調べ直し、タミル語の格語尾・活用・構文の解説を置換して使わない |
| 音声・字幕 | 投稿元、音声の言語、版、字幕の言語と手動／自動の別を確認する。日本語字幕や自動翻訳を原語の原文として扱わない |
| 利用検証 | 本文取得、映像・音声の再生、原文照合を別々に検証する。別言語版でのYouTube取得結果を今回の確認結果として転記しない |
| 作品ノート | ひな形を使い、原文・訳・文法・出典は対象の言語版として新たに調べる |

辞書・文法資料は共通の [SOURCES](SOURCES.md) にまとめます。

## ノートの整理

作品ごとにフォルダを作り、台詞・歌詞を保存します。台詞は `dialogue/dialogue.md` の1ファイルにまとめ、台詞ごとの見出しの下を指定の5区分で構成します。新しい台詞も同じファイルに追記します。歌詞は `songs/` に曲ごとに1つのMarkdownファイルを保存し、同じ曲の抜粋・解説はそのファイルに追記します。ファイル名は `Saahore-Baahubali.md` のように曲名を使い、先頭の見出しも曲名だけにします。番号や解説テーマをタイトルに付けません。新しいノートは `movies/_template/` の台詞・歌詞のひな形を使います。作品の一般情報はWikipediaなどを参照し、このリポジトリに作品紹介ページは作りません。

```text
movies/
└── <作品名>-<公開年>/
    ├── dialogue/
    │   └── dialogue.md  # この作品の台詞を1ファイルにまとめる
    └── songs/
        ├── Song-Title.md
        └── Another-Song.md
```

個別の台詞・曲名や確認の進み具合は、各ノートで管理します。

作業ルール・保存先・アクセス範囲は [AGENTS](AGENTS.md)、共通の辞書・文法資料は [SOURCES](SOURCES.md) にまとめています。台詞の追加には [台詞ひな形](movies/_template/dialogue/dialogue.md)、曲の追加には [歌詞ひな形](movies/_template/songs/Song-Title.md) を使います。

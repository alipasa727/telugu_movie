# 映画の台詞と歌詞で学ぶテルグ語

映画の台詞と歌詞を題材に、テルグ語の表現がどのように意味を作るかを学ぶためのノートです。テルグ文字が読めることを前提に、**原文・日本語訳・文法解説**を結び付け、別の場面でも使える理解を積み重ねます。

## 学習の方針

原文を読み、語幹と接辞の働きを追い、訳の根拠を自分で説明できることを目指します。場面や人物関係も合わせて読むことで、辞書の訳語だけでは分からない語調や使い方を理解します。

映画の会話では口語の短縮や省略を、歌詞では比喩・反復・詩的な語順を学びます。それぞれの表現が日常会話でどう使えるかも考え、作品中の言い方と一般的な用法を区別します。

テルグ文字を本文の中心に置きます。ローマ字やカタカナは必要な場合の補助とし、発音は音声で確かめます。

## 教材の選び方

テルグ語の台詞・歌詞から、学習したい表現や文法に合う箇所を選びます。テルグ語原語版と吹替版を区別し、使用する音声・字幕・掲載原文の言語を確認します。一つのノートでは、意味と構造を説明できる一続きの発言・会話、歌詞の節・段落を扱います。

- 日常でも使える呼びかけ、質問、返答、依頼、否定などを取り上げる。
- 格、人称、時制、動詞の活用、連体修飾など、学ぶポイントが明確な箇所を選ぶ。
- 有名な決め台詞だけに偏らず、会話のやり取りや人物関係が分かる表現も増やす。
- 歌詞は比喩や省略を説明できる箇所を選び、理解に必要な前後関係を日本語で補う。

台詞は意味がつながる発言・やり取りを単位にし、次の5項目をこの順で置きます。

1. **本文**：確認した原文と、発言全体の自然な日本語訳。
2. **直訳**：主語・目的語・修飾関係を追える訳。
3. **語彙説明**：語句の意味と、文脈に合わせた訳語。
4. **文法説明**：格・活用・語順などが意味を作る仕組み。
5. **背景や要確認箇所等の補足**：背景、比喩、補った語句の根拠、表記差や未確認事項。

台詞ごとの「場面と出典」欄は設けません。採用資料・掲載範囲・確認日・語義や文法の根拠・音声等との照合記録は、各作品の `sources.md` にまとめます。

歌詞は節やサビなど小節のまとまりごとに、次の5項目をこの順で置きます。

1. **本文**：原文を、行の区切りを保って掲載。
2. **直訳**：まとまり全体の意味と構造を追う訳。
3. **語彙説明**：そのまとまりに出てくる語の意味と、辞書形との対応。
4. **文法説明**：語幹・接辞・活用・修飾や、行をまたぐ文のつながり。
5. **背景や要確認箇所等の補足**：自然な訳、文化的な背景、比喩、訳で補った内容、表記の差や未確認事項。

曲情報と共通の出典・確認範囲は、曲全体にまとめます。文法の都合で短い一文だけに切り分けず、指示語が受ける内容や比喩の流れが分かる範囲を選びます。別資料の文や離れた場面は合成せず、引用の範囲・省略・繰り返しを明記します。同じ歌詞の繰り返しは省略し、新しく現れる内容と表記差を残します。

## 原文と出典の扱い

原文には出典と確認状況を付けます。字幕、掲載歌詞、音声からの聞き取りなど、何を根拠に記録したかを明らかにします。場面、話者、相手、使用した映像・音源の版、タイムスタンプも、確認できた範囲で残します。

掲載資料での確認と、本編の音声・字幕との照合は分けて記録します。資料間で表記が違う場合は、その違いを注記します。聞き取れない部分や未確認の情報は推測で埋めず、確認事項として残します。

**台詞・歌詞は自作せず、必ず調べて出典を確認します。** 記憶やAIの生成文だけを根拠に、作品中の原文として掲載しません。原文が見つからない場合は作って補わず、掲載を見送るか未確認事項として残します。

日本語訳と文法解説は、確認した原文に基づいて作成します。原文にない内容を訳で補う場合は、その旨を明記します。

## 調査に使う資料

台詞・歌詞は、ユーザーが提示した本文・画像や、本編・公式字幕・公式歌詞など、実際に採用する原文を基にします。提供本文と本編の音声・字幕との照合状況は区別し、原文を自作したり、未確認の表記を推測で埋めたりしません。

語義や文法の確認には辞書・文法書・教育資料を使います。共通の参照先と確認範囲は [辞書・文法資料](SOURCES.md) にまとめています。採用原文の範囲と個別の根拠は各作品の資料記録・ノートに残し、使わなくなった映画サイトの候補一覧や取得履歴は管理しません。

## 日本語訳の方針

**自然な訳**では、場面に合う日本語で意味と語調を伝えます。**直訳**では、主語・目的語・修飾関係や接辞の働きが追えるように訳します。

省略された主語や目的語を補った場合は、補った内容と根拠を説明します。人称の訳し分け、丁寧さ、感情、比喩など、解釈が入る部分も原文の意味と分けて示します。複数の読み方がある場合は、無理に一つに決めず、文脈に合う解釈と残る疑問を記録します。

日本語訳は学習用に作成した訳として扱い、公式字幕や既存の翻訳を参照した場合は出典を記します。

## 文法解説の方針

解説は、実際の原文に出てくる形から始めます。単語の意味に加え、語幹・接辞・活用を分解し、それぞれが文中で何をしているかを説明します。

**文法事項も、文法書・大学や教育機関の教材で調べて根拠を確認します。** 語義は辞書、格・活用・構文は文法資料で確認し、口語と書き言葉のどちらを説明する資料かも記録します。台詞の参照した節・ページと照合記録は各作品の `sources.md` にまとめ、未確認の分析は台詞の補足でも明示します。歌詞は各曲のノートに確認記録を残します。

参照先と確認範囲は [テルグ語の辞書・文法資料](SOURCES.md#テルグ語の辞書文法資料) にまとめています。根拠を確認できない分析は未確認と明記し、AIの説明だけで確認済みにはしません。

- 格を表す接辞と、動詞の時制・人称・数などを示す形を区別する。
- 単語の分解だけで終わらず、文全体の構造と日本語訳へのつながりを示す。
- 口語形と書き言葉の形は、対応が確認できた場合に併記する。
- 歌詞の比喩や反復は、文字どおりの意味と表現上の効果を分けて説明する。

一つの語尾を常に同じ日本語に置き換えるのではなく、その形の働きと文脈の両方から読むことを重視します。

## 内容の更新

新しい資料で誤りや別の解釈が分かった場合は、原文・訳・解説を見直し、未確認だった点を更新します。

## 言語版と資料の区別

このノート集ではテルグ語版を扱います。原文・訳・文法・出典はテルグ語の資料で調べ、タミル語など別言語の資料の確認結果を転用しません。

| 項目 | 確認する内容 |
| --- | --- |
| 原語・文字・作品情報 | テルグ語の原題・公開年・曲名を確認し、タミル語の原作とテルグ語吹替版を区別する |
| 台詞・歌詞の原文 | 提供本文・画像や採用資料の言語と作品を確認する。別言語版の原文や検証結果を転用しない |
| 辞書・文法資料 | テルグ語の資料で調べ直し、タミル語の格語尾・活用・構文の解説を置換して使わない |
| 音声・字幕 | 投稿元、音声の言語、版、字幕の言語と手動／自動の別を確認する。日本語字幕や自動翻訳を原語の原文として扱わない |
| 利用検証 | 本文取得、映像・音声の再生、原文照合を別々に検証する。別言語版でのYouTube取得結果を今回の確認結果として転記しない |
| 作品ノート | ひな形を使い、原文・訳・文法・出典は対象の言語版として新たに調べる |

辞書・文法資料の参照先は [SOURCES](SOURCES.md)、各表現の根拠と確認の限界は各作品の資料記録に残します。

## ノートの整理

作品ごとにフォルダを作り、作品情報とノートの一覧は各作品の `movie.md` にまとめます。台詞は `dialogue/dialogue.md` の1ファイルにまとめ、台詞ごとの見出しの下を指定の5区分で構成し、出典・確認記録は各作品の `sources.md` にまとめます。新しい台詞も同じファイルに追記します。歌詞は `songs/` に曲ごとに1つのMarkdownファイルを保存し、同じ曲の抜粋・解説はそのファイルに追記します。ファイル名は `Saahore-Baahubali.md` のように曲名を使い、先頭の見出しも曲名だけにします。番号や解説テーマをタイトルに付けません。新しい作品には [ひな形](movies/_template/movie.md) を使います。

```text
movies/
└── <作品名>-<公開年>/
    ├── movie.md
    ├── dialogue/
    │   └── dialogue.md  # この作品の台詞を1ファイルにまとめる
    └── songs/
        ├── Song-Title.md
        └── Another-Song.md
```

個別の台詞・曲名や確認の進み具合は、各作品のページで管理します。

作業ルール・保存先・アクセス範囲は [AGENTS](AGENTS.md)、共通の辞書・文法資料は [SOURCES](SOURCES.md)、採用原文と個別の確認記録は各作品の資料記録にまとめています。台詞の追加には [台詞ひな形](movies/_template/dialogue/dialogue.md)、曲の追加には [歌詞ひな形](movies/_template/songs/Song-Title.md) を使います。
